## What I actually did

- Ran the full five-request story creation sequence end to end (instant_stories, characters, character model, story model, story page_text). Completed cleanly — text, moderation, character image, cover image, and all page images generated in ~12 minutes, consistent with known serial async-shared-pool throughput. Closes the open item carried since the executor restructure; story generation is proven working. (Throughput itself remains a Phase 2 concern per [[defer-image-pipeline-throughput-to-phase-2]] — off-Xano parallel pipeline during the Bedrock migration.)
- Built a dedicated Postman collection, "Tomale — Flow Tests," separate from the OpenAPI-imported collection so a future OpenAPI reimport can't clobber hand-built tests. Two folders in execution order: `auth` and `story generation`, with collection-level Bearer auth.
- Added chained-id capture as run-scoped collection variables (`storyId`, `characterId`) with fail-fast assertions, replacing hardcoded test ids across the model and page_text requests; added pre-request cleanup of stale ids so a failed run can't taint the next one.
- Handled async completion via a manual gate (run the five POSTs, wait ~15 minutes, then one `GET /instant_stories/{{storyId}}` asserting completeness) rather than self-polling, since polling scaffolding built around the current 12-minute figure would be throwaway once the off-Xano pipeline lands.
- Marked the story-generation flow test done.
- Started order-fulfilment test design: reframed the remaining Phase 1 flow-test scope down to (1) the still-unfinished A1 create_checkout_session assertion and (2) the joined end-to-end payment→HPBC proof, since the individual hops (Stripe webhook branches, both HPBC callback endpoints) were already proven in July. Mapped the live chain: store_order → create_checkout_session → payment → webhook_payment_confirmation → PDF orchestrator → DB trigger → HPBC callback. Identified three candidate approaches for driving the Stripe payment hop in a test (Stripe CLI, a dev-only simulate flag, manual browser checkout); leaning toward Stripe CLI for a one-off real proof plus a simulate flag for the repeatable harness.
