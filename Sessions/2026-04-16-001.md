## Decisions made

- `worker_tick` endpoint dropped for V1 — cron job running every 2 mins is sufficient, no need to expose manual trigger
- `page_image` endpoint uses filter (not fail-fast) approach — creates jobs only for pages with content, returns summary of jobs created and pages skipped so AI chatbot can reason about and retry if needed
- `cover_image` and `page_image` endpoints output `image_job` records (status = queued) — worker tick picks up asynchronously, endpoints do not call executor directly
- `store_orders` POST inputs reduced to minimum for now — ecommerce-specific fields (status logic, products, size, orientation) deferred to ecommerce build phase
- `store_orders` PATCH limited to `status` and `message` only for V1
- Order number format confirmed: `{id}-{yyyymmdd}-{users_id}-{instant_stories_id}`
- `transaction_webhook_events` and `transactions` CRUD endpoints deleted — tables retained, written to only via internal webhook handler functions
