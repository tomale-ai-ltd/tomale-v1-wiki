## Learnings

- Web screenshots can't prove native rendering: CSS variables in colour props work on web only.
- A mock-up's backdrop (the page behind a sheet) must be labelled as such, or it gets built as content.
- Case-only file renames break on macOS's case-insensitive filesystem; keep file names stable.
