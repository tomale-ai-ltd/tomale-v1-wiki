## Learnings

- Postman exports only initial values; Replace on import blanks current values. The environment beats the collection: a blank collection copy of a variable silently wins after an import if the environment lacks it. Keep credentials (test PIN) in the environment only; choose Replace, not copy.
- Postman reports a request skipped via `pm.execution.skipRequest()` as "could not be sent" (5D-2/5D-3 are gated by `runImageTests`).
- Wrong-PIN tests with a blank PIN variable lock the account; folder 6 now guards against it.
- Xano Run & Debug can simulate auth extras via Advanced Auth Settings → Set Auth Token Extras (`{"active_profile": {id, name, is_child, is_primary}}`), so stack-built responses can be checked before publishing.
- Xano AI: check table names in generated code (blank `""` names); `$output` is reserved.
- A change set marked done in a brief isn't proof it reached every endpoint: check the mirror.
