## Decisions made

- **Refresh the Xano mirror with a Mac launchd job, not by giving an agent GitHub credentials** (Kyle, 03/11, accepted). `ai.tomale.xano-pull` runs `git pull --ff-only` in `tomale-xano` at 17:30 weekdays with Kyle's own GitHub access (source `Project/Automation/ai.tomale.xano-pull.plist`, log `~/Library/Logs/tomale-xano-pull.log`). Why: the pipeline's shell has no credentials, and Kyle's GitHub login can push to every repo, too broad for an unattended agent. Alternatives: give the task shell Kyle's login (rejected: scope), a read-only deploy key (rejected: key would sit in an agent-readable folder), manual pulls only. Loaded and tested 03/11.
