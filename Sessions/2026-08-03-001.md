## What I actually did

- Diagnosed a cluster of bugs from an executor_runs export: plaintext OpenAI API key logged in api_request, duplicate executor runs from a lease-timing bug, base64 image payloads bloating api_response (72MB for 28 rows), unreachable error branches in executor_page_image (`$exec.result.ok` referencing an out-of-scope variable), and serial image processing (~13 min for a 12-page story).
- Root-caused the duplicate runs: leases were granted at claim time (180s window) but serial processing took ~13 min, so leases expired mid-job and the recovery reaper requeued still-running jobs.
- Redrafted all three image executors (executor_page_image, executor_cover_image, executor_character_image): extended leases at execution start rather than claim time, added local `$now` scoping, whitelisted api_request/api_response to url/method/params/status (dropping auth headers and base64 payloads), fixed the `$exec.result.ok` → `$result.ok` bug in executor_page_image's error branches, replaced the images_remaining decrement with a self-correcting recount of null-image pages, and fixed a copy-paste filename/variable artefact in executor_page_image.
- Confirmed with founder that images_remaining recount logic (page images only, cover excluded) is correct given cover/page jobs are queued separately with cover at higher priority.
- Set up a third Postman collection (metadata) for the Xano Metadata API, using a separate privileged access token. Discovered the function_history endpoint takes page/per_page/branch/function_id/include_output as query params, not JSON body — passing them in the body silently returned unfiltered results. Noted retention: function runs 24h, background tasks 7 days, confirming executor_runs remains the durable source of truth.
- Ran a clean end-to-end test: created story 606 via API, fired page_text (13 jobs queued: 12 pages + 1 cover). No duplicate executor runs — lease fix confirmed working. Run took ~22 minutes with retry counts rising per batch (1, 3, 5 tries), suggesting OpenAI rate limiting later in the run.
