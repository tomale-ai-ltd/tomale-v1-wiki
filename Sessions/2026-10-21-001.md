## Decisions made

Deviations from the baseline docs (need manual decision notes in `Project/Decisions/`; none created by this automated run):

- **Client tokens move from AsyncStorage to `expo-secure-store`**, settling the "future hardening decision" in `9. AsyncStorage.md` (deviates from the stack docs).
- **Client auth session handling:** single Axios response interceptor on 401 (shared single refresh, one retry, never for `/auth/*`); on `invalid_refresh_token` clear tokens, reset Zustand auth store, Expo Router root layout redirects to login; network errors don't log out; proactive refresh before the 1-hour expiry on foreground.
- **Rate limiting:** Xano paid plans have no platform-level limit, so per-endpoint Rate Limit functions are needed (auth, order create/cancel, story/image generation). Phase to confirm; Phase 2 before launch recommended.
- **Fix before Phase 1 sign-off:** money units to integer pence (`subtotal`, `shipping_amount`); block ordering of stories awaiting parental approval.

Other decisions (not deviations): `/admin/upload/image` disabled until image-to-image work; `/model` endpoint deleted; test switches (`simulate_*`) are optional inputs, never required; executor runs log only small status fields, never full payloads.
