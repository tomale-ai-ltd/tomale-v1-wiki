## Decisions made

To file as decision notes (Kyle decided, 30/10):
- **Mirror Canonical, Decisions, the constitution and the data model into Claude Project knowledge,** synced by the daily pipeline using a hash manifest (`Project/Automation/project-sync-manifest.json`); the April hand-uploaded docs are retired.

- **Track hand-maintained agent context copies by fingerprint** ([[agent-context-sync]]): each rule has one home; the pipeline raises a pending-updates item when a source changes and records the fingerprint when Kyle marks it applied.
- **Replace the two daily vault tasks with one daily knowledge pipeline (17:40 weekdays) plus a weekly staleness check (Mondays 10:17).**

Recorded in [[repo-sync]] rather than as decision notes: the pnpm dependency approach and accepted exceptions (RS-2026-10-24-03), `web.output` single, the typecheck fixes, the Cursor raw-note convention. These include (from Cursor's B10 raw note):
- Kyle approved pnpm 10 (not 11), a 7-day `minimumReleaseAge`, and build scripts only for `@sentry/cli` and `unrs-resolver`.
- Kyle approved same-major overrides for highs, and `ignoreGhsas` when the fix is a major bump under Expo, Metro or Jest, or when there is no patch. Runtime packages are not accepted.
- Kyle rejected the `decode-uri-component` 0.2 → 0.5 override (0.5.1 is ESM-only; `query-string` 7 is CommonJS). The high stays ignored; the lockfile stays on 0.2.2.
- Cursor set `node-linker=hoisted` because Jest could not transform `react-native/jest/setup.js` under `node_modules/.pnpm`.
- Cursor pinned `lint-staged`, `prettier` and `yaml` to the npm-lock versions after a fresh resolve floated those ranges.
