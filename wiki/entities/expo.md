# Expo

## Facts

- Zustand runs client-side in the Expo managed app.
- Allows fast development with native capabilities without managing native code directly.
- Runs within Expo managed workflow.
- Theming configured globally for colours, typography, spacing.
- Used in conjunction with React Native for frontend development.
- Mentioned in relation to OTA updates and versioning.
- Expo is used in conjunction with React Native for building the application.
- Expo's release channels map to version types for the Tomale project.
- Refactored api/http.ts to read from the env module.
