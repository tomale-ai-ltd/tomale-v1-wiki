# PU-2026-11-19-03: sign out of all devices, and revoke-all for incidents

Agreed 19/11: a parent can sign the household out of every device; sessions are **not** revoked on OTA, minor or major updates (every family would need a new magic link on each release). A forced sign-out of everyone is an incident tool only: a leaked token or signing key, a change to how tokens are signed, or a session change old tokens can't survive.

- **[[pre-launch-checklist]] §1:** after the "Server-side sign-out" line, add:
  - "- [ ] **Sign out of all devices:** a shared Xano function `auth/revoke_all_sessions` marks every `user_sessions` row for the account `revoked`; `POST /auth/logout_all` (parent profile only, `PARENT_PROFILE_REQUIRED`; PIN if set, `PIN_INVALID`) calls it, and account closing (B2 in [[account-closing-micro-prd]]) uses the same function. Open: revoking only stops refresh, so a 1-hour access token on another device keeps working until it expires; decide whether the auth check should look up the session on each request."
  - "- [ ] **Emergency revoke-all (incident runbook):** an admin-only Xano function that revokes every session for every account, with the steps written in the runbook (when to use it: leaked token or signing key, signing change, breaking session change). Not run on app updates."
- **[[roadmap]] M7:** after the Account deletion bullet, add "- **Sign out of all devices** in Settings (parent only, behind the PIN), on the shared revoke function ([[pre-launch-checklist]] §1)."
- **[[account-closing-micro-prd]] B2:** change "revokes every `user_sessions` row" to "revokes every `user_sessions` row through the shared `auth/revoke_all_sessions` function (also used by sign out of all devices)".
- Independent of PU-2026-11-19-02 (which rewrites the account-deletion checklist line); either can be applied first.
