# RS-2026-11-12-02: Simulator screenshot script

- Change: add `scripts/sim-shot.sh <name> [route]` and `pnpm shot <name> [route]`. With an iOS Simulator booted and the development build running (Metro on), it optionally opens `tomalerntest://<route>` with `xcrun simctl openurl booted`, waits ~2 s, and saves `xcrun simctl io booted screenshot` to `.screenshots/<name>.png` (light). With `--dark` it switches `xcrun simctl ui booted appearance dark` first and restores light after. `.screenshots/` is git-ignored. If no simulator is booted, it says so and exits non-zero.
- Use: the agent runs it after each UI change, opens the PNG, compares it with the target in `specs/<feature>/design/png/`, fixes differences, and repeats before reporting a screen as done. It shows Kyle the final screenshot pair (mock-up and build).
- One-off setup (Kyle, once): a simulator development build (`npx expo run:ios` or an EAS simulator build) installed in the Simulator. Ask Kyle before installing anything.
- Speckit impact: every UI task's done-check includes a screenshot comparison.
- Verify: `pnpm shot test characters` writes `.screenshots/test.png` showing the Characters tab; `--dark` gives a dark one.
