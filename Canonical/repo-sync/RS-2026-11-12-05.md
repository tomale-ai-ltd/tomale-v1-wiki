# RS-2026-11-12-05: ui.mdc additions after the 008 device check

Add to `.cursor/rules/ui.mdc`:
- **Colours on native:** never pass a CSS variable string (`"var(--x)"`) to a colour prop (`color`, `fill`, `stroke`, `backgroundColor`, `placeholderTextColor`, `tintColor`, etc.). It works on web only; on iOS and Android it is invalid and renders nothing or a default. Use className-based styling, or resolve the theme token to a value with the project's theme hook.
- **Keyboard:** every screen or sheet with a text input keeps the focused field and its submit button visible above the keyboard on iOS and Android (keyboard-avoiding container; scroll the field into view).
- **Web screenshots don't prove native rendering:** the web loop checks layout and spacing; a screen isn't done until Kyle has seen it on the phone (icons, colours in both themes, scroll performance).

- Verify: rule present; `git grep 'var(--' components app` finds no colour props.
