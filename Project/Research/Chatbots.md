## Building a Chatbot with OpenAI/ChatGPT and Xano

![](https://www.youtube.com/watch?v=fnH8KjiUjYc)
This guide will walk you through building a chatbot using ChatGPT and Xano. Before we begin, it’s important that you understand the following key concepts: [Database Basics](https://docs.xano.com/the-database/database-basics) [Building with Visual Development](https://docs.xano.com/the-function-stack/building-with-visual-development) [APIs & Lambdas](https://docs.xano.com/the-function-stack/functions/apis-and-lambdas) [User Authentication & User Data](https://docs.xano.com/building-backend-features/user-authentication-and-user-data) You should know how to build a database table, build basic function stacks, work with user authentication, and utilize the External API Request function.
