## Why was this added to the vault?

-  Connecting Xano to Cursor might enable us to accelerate the tomale-rn-v1 build.
- Tools like the Xanoscript cursor extension might help write Xano functions rapidly using cursor.
- The MCP might allow Cursor to have context of the backend 'live', so any changes to the backend are automateically reflected in Cursor when building the frontend.
- We need to research this further ASAP.

___

## Cursor

AI-powered IDE for developers. Use Xano to generate 1-click MCP (Model Context Protocol) install deeplinks, allowing seamless backend integration with Cursor workflows.

## Plugins

Native plugins and extensions that enable direct connectivity between Cursor and Xano.
### [XanoScript Extension for Cursor](https://open-vsx.org/extension/xano/xanoscript)

Syntax highlighting and IntelliSense for XanoScript in Cursor. Makes writing Xano functions a breeze.

## Actions

Pre-built function stacks you can import directly into your Xano workspace to connect with Cursor.
### [Cursor -> Create 1-click MCP Install Deeplink](https://www.xano.com/actions/run/xano/cursor-1-click-mcp)

Generate one-click MCP installation links for Cursor. Help developers get started instantly.
