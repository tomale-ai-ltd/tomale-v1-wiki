# Characters mock-ups (source)

HTML source of the "Tomale Characters screens" Design canvas (artifact SenvcjE1ZW4peaQpiz3oRG), exported 12/11/2026. Each `*.dc.html` is one artboard at 390 px wide: layout, colours (hex from the Tomale tokens), radii, spacing and type sizes are inline. `canvas.json` lists the artboards and their titles. `Art` and `TabBar` are shared parts; `support.js` and the fonts are not included (the fonts are in `Project/Research/brand/fonts`).

Chosen designs: Characters (grid), CarouselParallax (parent carousel), CharactersChild (child carousel), CharacterDetail, QuickActions (More sheet), DeleteConfirm, DrawAgain, CreateCharacter, CharactersEmpty, CreateSheet. Not chosen: CarouselCircular, CarouselWallpaper. 501 (ChatCreate, ChatPreview, Reveal) is for speckit 012.

PNG renders of each artboard: `png/` (exported from the canvas by Kyle).
