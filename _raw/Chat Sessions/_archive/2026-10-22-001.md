## Decisions made

- **`store_orders` money fields are integer pence** (`subtotal`, `shipping_amount`), matching `products`, `shipping_options` and `transactions`. Rows migrated in place. HPBC still receives pounds, converted at dispatch in `hpbc_create_order`. Extends [[store-money-as-integer-minor-units]] to `store_orders`.
- **Don't enable Xano's workspace-level Hidden Fields setting.** Every existing statement explicitly sets `enforce_hidden_fields = false`, so the setting changes nothing, and it could null hidden fields read without an `output` list (`user_sessions.refresh_token`, `users.password`). Instead, a **pre-launch sweep** switches every `db.add` / `db.edit` to `enforce_hidden_fields = true`, maps every written column explicitly and adds `output` lists where hidden fields are read, followed by a full `_tests` run. Added to the pre-launch checklist alongside rate limiting.
- **Prefer the statement-level `enforce_hidden_fields = true` flag over renaming inputs** that are part of an external contract (e.g. `auth/login` `password`, HPBC payload fields).
- **Replace `dblink` inputs with explicit allowlists** on any endpoint or function that edits records. Hidden overrides are a blocklist and expose any column added later.
- **Review Xano AI output against the published version before pasting** (matching `guid`, nothing dropped). The Xano AI can build from stale drafts.
- **Postman:** login tokens are set run-scoped (`pm.variables.set`) in 1A; the legacy `app` folder auto-login script is removed.
- **Parental-approval order gate:** `parental_approval_required && !parent_approved` → 400 `STORY_AWAITING_APPROVAL` on order create and checkout (built 23/10).
