## Decisions made

- **Upgrade Expo SDK 54 → 58 in M1, then use gluestack-ui v5 with UniWind** (Kyle, 01/11, accepted; replaces an earlier same-day choice of gluestack-ui v3). Why: gluestack v3's overlays (Modal, ActionSheet, Popover) break or crash on Expo SDK 54 with Reanimated 4 (gluestack issue #3200, no clean fix), and we need overlays from Slice 100. v4 never left alpha; v5 (5.0.15, June 2026) is current stable and moves most overlays to Reanimated (ActionSheet, Select, Tooltip still use Legend Motion). v5 needs Tailwind v4 via NativeWind v5 (still RC) or UniWind (stable, Expo-only): chose UniWind. gluestack's own Expo starter runs SDK 56 / Reanimated 4.3; Expo latest is SDK 58 (29/09/2026); upgrading now, with no feature screens, is the cheapest it will be. Alternatives: SDK 56 (gluestack's tested version, shorter support window), re-open the library choice (e.g. Tamagui). Trade-offs: 1–2 days added to M1; gluestack repo activity slowed since July (mitigated: components are copied into our repo). SDK 58 needs Node ≥ 22.13. Affects: constitution, [[stack]], [[roadmap]] M1.
